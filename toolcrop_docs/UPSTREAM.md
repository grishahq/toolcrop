# Attribution and baseline

ToolCrop builds on [Bespoke Labs Curator](https://github.com/bespokelabsai/curator), preserved at commit `7fa08c5207c3b1fd5c1d0f15f1dc25a6547a3d8a`. Its complete history, source, examples, documentation and Apache-2.0 LICENSE remain in this fork. The upstream README is preserved in UPSTREAM_README.md. Upstream package version at the fork is 0.1.29.

Curator supplies structured outputs, provider integrations, retries, caching, bulk inference, function-calling examples and agent conversations. ToolCrop adds the inventory task specifications, reference planner, Curator recipe adapter, bounded executor, independent goal checks, corruption experiment, exports and launch evidence. This fork is not an official Bespoke Labs release. The original upstream package remains available separately as bespokelabs-curator; do not install both distributions in the same environment because both own the Curator namespace.

No upstream NOTICE file was present at this commit. Existing license and embedded attribution are retained. New ToolCrop code is distributed under the same Apache-2.0 license. ToolCrop is a working project name, not trademark clearance.
